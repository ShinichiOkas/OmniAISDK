# mlx-lm: ツール呼び出し・構造化出力・画像入力（次スプリントで必ず実装）

- 起票: 2026-11-15（mlx-lm プロバイダー追加スプリント 875db2c1 の協議中）
- 師匠の発話（原文）: 「ツール呼び出しや号増加出力、画像入力は実用上は必要なので、次ステップでは必ず実装する前提で進めて」
  - 「号増加出力」＝構造化出力（response_schema）
- 位置付け: 任意の改善ではなく**必須**。mlx-lm 初版の直後のスプリントで扱う

## 対象

1. ツール呼び出し（tools / tool_choice）
2. 構造化出力（response_schema）
3. 画像入力（mlx-vlm の利用を想定）

## 初版の状態

3 つとも `UnsupportedFeatureError` を返す。初版の設計は、この 3 つを後から足せる形にしてある（合意ドキュメント J-M7）。
