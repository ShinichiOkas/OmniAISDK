| O-01 | 「Google」を Gemini Developer API（AI Studio・APIキー認証）と解釈し、Vertex AI は使わない | キーが GEMINI_API_KEY だったため |
| O-02 | Gemini は generateContent（v1beta）を使う。公式が既定としている Interactions API は使わない | ツール・ストリーム・エラーの資料がそろっているのが generateContent のため。codec を差し替えられる構造にしておく（R-01） |

| O-04 | Ollama の既定モデルは持たない（必須引数にする） | 手元のモデルが利用者ごとに違うため |
| O-05 | sans-IO 方式で同期・非同期を二重に実装する（ADR-06） | Jupyter などで同期 API が壊れないように |
| O-06 | ADR-07〜12 を追加（ストリームのフォールバック、再試行との順序、組み込みツールの自己申告、コストの None、provider_state、OmniTool） | 設計書 §2 |
| O-07 | 仕様書 §8.5 の「agenerate だけで自動代行」をやめ、ToolRunner に移した | 呼び出しごとにコストと履歴の意味が変わるため |
